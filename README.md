# CheckPoint 2: Catálogo de Atores

Aplicativo web simples desenvolvido com **HTML, CSS e JavaScript puro** para listar e buscar atores e atrizes.

## Funcionalidades
- Exibe uma lista de atores em formato de grid.
- Campo de busca em tempo real para filtrar os cards pelo nome do artista (usando `filter()` e `includes()`).

## Tecnologias
- **HTML5**
- **CSS**
- **JavaScript** 

## Como rodar o projeto
Não é necessário instalar nada. Siga os passos:
1. Faça o download ou clone este repositório.
2. Certifique-se de que os arquivos `index.html`, `style.css`, `script.js` e `dados.js` estão na mesma pasta.
3. Abra o arquivo `index.html` no seu navegador.
